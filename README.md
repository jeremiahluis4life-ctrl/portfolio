# Portfolio: Onyekachi Jeremiah

Personal portfolio website for Onyekachi Jeremiah, frontend developer.

## Sections
- Hero with a glass-effect animation
- About
- Work: project gallery with images and video showcases
- Stack: tools and technologies
- Contact

## Features
- Light/dark theme toggle
- Responsive layout
- Animated sections and project gallery

## Tech stack
HTML, CSS and vanilla JavaScript. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.
